01 — The problem

AI agents can't tell data from orders.

To a language model, everything is just text. When an assistant reads an email, a PDF or a web page, any instruction hidden inside it competes with yours, and often wins. OWASP ranks prompt injection as the number one security risk for LLM applications.

#1Risk in the OWASP Top 10 for LLM apps
0clicks needed: the victim only asks a normal question
1hidden sentence is enough to trigger the attack
02 — How the attack works

Three steps from inbox to empty account.

The attacker never touches the AI directly. They just leave a trap where the AI will look.

1

Plant

The attacker hides an instruction in white text, an HTML comment or PDF metadata, inside an email, resume or product review.

2

Trigger

The user innocently asks their assistant to "summarise my email". The agent pulls the poisoned document into its prompt.

3

Execute

The model treats the hidden text as a command and calls its tools: it transfers money, leaks data or lies to the user.

03 — The defense

Five layers, not one magic prompt.

No single trick is enough, so the arena stacks five defenses. Flip the shield in the demo and watch each one fire.

L1

Hidden-text scan

Exposes invisible and zero-width text before the model sees it.

L2

Injection classifier

Flags phrases like "ignore previous instructions".

L3

Spotlighting

Wraps documents in data markers the model is told never to obey.

L4

Tool policy guard

Blocks any action the user didn't actually ask for.

L5

Human confirmation

Risky actions go back to the user for approval.

05 — Setup

Run it on a real AI, for free.

Simulation mode works offline and is the safest for a live presentation. To prove it on a real model, get a free key from either provider below. Both work straight from this page with no server.

Google Gemini

Free · recommended
  1. Go to aistudio.google.com/apikey and sign in with any Google account.
  2. Accept the terms if asked, then click Create API key.
  3. Choose Create API key in new project (or pick an existing project).
  4. Copy the key. It starts with AIza.
  5. In the arena, set Engine to Google Gemini (free) and paste the key.
  6. Leave the model as gemini-3.8-flash. If Google has retired it, use any "flash" model listed in AI Studio.
  7. Pick an attack and press Run.

Groq (Llama)

Free · very fast
  1. Go to console.groq.com/keys and sign up with Google or GitHub.
  2. Click Create API Key and give it any name.
  3. Copy the key straight away (it starts with gsk_). It's shown only once.
  4. In the arena, set Engine to Groq · Llama (free) and paste the key.
  5. Leave the model as llama-3.3-70b-versatile, or pick another from Groq's model list.
  6. Press Run.
Before your presentation: real models are not predictable. A strong model may resist an attack one time and fall for it the next. Rehearse in live mode, but present in Simulation so the demo never fails on stage. Never share your key or commit it to GitHub. If it leaks, delete it in the same console and make a new one.
